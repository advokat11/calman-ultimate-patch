# CalMAN 5 for Business — офлайн-патч лицензий

Скрипты снимают зависимость CalMAN от лицензий на **приборы, источники сигнала и дисплеи**.
Без этого программа подменяет реальный прибор на «Simulated meter» (обманку), пишет в лог
`Error: 26 - ERR_LICENSE_METER: Meter license not found` и показывает приборы красным.

## Быстрый старт

```
calman-patch-universal.bat            применить
calman-patch-universal.bat restore    откатить
calman-patch-universal.bat ?          справка
```

Запускать **от имени администратора**, CalMAN должен быть закрыт (скрипт закроет его сам).
После патча заголовок в программе должен читаться `Calman Ultimate for Business`, приборы поднимаются,
в логе нет `Error: 26`.

**Универсальный скрипт не содержит адресов** — он находит все пять точек сам:

| Что ищет | Как ищет |
|---|---|
| `LicenseDescription::get_Value` (managed) | разбор метаданных .NET: TypeDef `LicenseDescription` → MethodList → MethodDef `get_Value` → RVA → тело `1E 02 7B … 2A` |
| `ApplicationLicensing::SiteLicense` (managed) | там же: TypeDef `ApplicationLicensing` → MethodDef `SiteLicense` → RVA → fat-заголовок `1B 30 …` |
| гейты метров / источников / дисплеев (native) | строки `XML MeterLicense failed…` / `XML SourceLicense failed…` → ссылка `push offset` в `.text` → начало функции; тип определяется по литералу XML-элемента (`Meters` / `Sources` / `Displays`) |

Каждая правка сверяет исходные байты («оригинал» или «уже пропатчено»); если мишень не найдена или не совпала —
печатается причина, правка пропускается, скрипт выходит с ненулевым кодом. Ничего не «угадывается».
Резервные копии — `<файл>.orig`.

## Проверено

| Проверка | Результат |
|---|---|
| 5.17.4.16, 5.17.5.3, 5.17.6.7 (`msiexec /a`-копии) | найдены и пропатчены все 5 точек в каждой сборке |
| Повторный запуск | все пять «already patched», запись не производится |
| `restore`, затем патч заново | файлы возвращаются к оригиналу и снова патчатся |
| Сверка с эталоном | `CalMAN_Workflow.dll` 5.17.5.3 после универсального скрипта **байт-в-байт** совпал с установленной пропатченной сборкой |

## Версионные скрипты (оставлены для справки)

| Версия CalMAN | Скрипт |
|---|---|
| 5.17.5.3, 5.17.4.16 (точки патча совпадают до байта) | `calman-ultimate-patch.bat` |
| 5.17.6.7 | `calman-ultimate-patch-5.17.6.7.bat` |

У них жёсткие офсеты: при другой версии CalMAN они останавливаются с сообщением (`unexpected bytes …`),
ничего не записывая. Предпочитайте универсальный.

## Что правится

| # | Файл | Место | Эффект |
|---|---|---|---|
| 1 | `CalMAN_Workflow.dll` | `LicenseDescription::get_Value` | сообщает лицензию 81 = «Calman Ultimate for Business» |
| 2 | `CalMAN_Workflow.dll` | `ApplicationLicensing::SiteLicense` | всегда `true`: нет онлайн-проверки и стирания лицензий |
| 3 | `Common\calmanv5.dll` | гейт метра | прибор считается лицензированным |
| 4 | `Common\calmanv5.dll` | гейт источника | источник считается лицензированным |
| 5 | `Common\calmanv5.dll` | гейт дисплея | дисплей считается лицензированным |

Правки — замена нескольких байт в начале функций («сразу вернуть да»); размеры файлов не меняются,
остальной код и драйверы приборов не затрагиваются. Проверку целостности каталога фич
(`FeaturesRoot/@Version`) скрипты намеренно не трогают.

## Ограничения

* Патч добавляет только то, что уже реализовано в самой программе: приборов, которых в CalMAN нет,
  он не создаёт.
* Все правки — в локальной копии приложения; само ПО здесь не распространяется.
